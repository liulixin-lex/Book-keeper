# dingdangdog/cashbook

- 分类：06 家庭私人记账（自托管）
- 语言 / 许可证 / 最近提交：TypeScript（Nuxt + Prisma + PostgreSQL）/ MIT / 2026-06（仅维护，作者在做新项目）
- 审查范围：`prisma/schema.prisma`、`server/api`、`docs/`

## 定位

适合家庭部署的私人记账本：多账本、预算、借出/应收、固定流水、支付宝/微信账单导入、账本分享。

## 数据模型

- **Flow（流水）**：日期、流水类型（收入 / 支出 / **不计收支**）、行业分类、支付方式、金额（float）、名称、描述、发票、**`origin`（来源：如“张三-支付宝导入”或“手动录入”）**、**`attribution`（归属人：谁的收入/支出）**、**`eliminate`（平账标志：0 未平账 / 1 已平账 / −1 忽略平账）**；
- **Receivable（应收/借出）**：借出流水 ID ↔ 收款流水 ID、发生日、**预计收款日**、实际收款日、金额、**状态（未收 / 已收 / 不要了 / 已放弃 / 不可抗力）**；
- FixedFlow（固定月度流水）、Budget（月预算与已用）、Book（含分享 key）。

## 可借鉴

- [CB1] 流水来源（origin）与归属人（attribution）分开记录。
- [CB2] “平账”：把互相抵消的流水（如转账两端、退款与原支出）标记为已平账，统计时剔除；可选择忽略。
- [CB3] 应收台账：发生流水 ↔ 结清流水、预计/实际日期、坏账类状态。
- [CB4] “不计收支”类型（内部转移不进统计）。

## 不采用 / 风险

- 浮点金额；单式；无审计。

## 对新系统的启示

- 交易记录 `source`（导入来源/渠道）与 `owner`（经办人/归属成员）分别保存；
- 往来未清台账状态包括“已核销 / 部分核销 / 放弃（坏账）”；
- 对“互相抵消”的交易支持配对核销（如退款与原收入、链动退款单与原订单）。
