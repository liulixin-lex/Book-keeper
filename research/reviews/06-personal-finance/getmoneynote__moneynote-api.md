# getmoneynote/moneynote-api（九快记账后端）

- 分类：06 个人/小店记账（中文）
- 语言 / 许可证 / 最近提交：Java (Spring Boot + JPA) / MIT / 2026-03
- 审查范围：`src/main/java/cn/biq/mn/{balanceflow,account,book,category,categoryrelation,payee,tag,group,noteday}`

## 定位

国内常用的开源记账方案（后端 + PC Web + Flutter App），面向个人生活和小店收支，Docker 一键部署。

## 数据模型

- **Group（组）→ Book（账簿）**：账簿属于组（家庭/团队），可设**默认支出账户、默认收入账户、默认转出/转入账户、默认支出/收入分类、默认币种**；
- **BalanceFlow（流水）**：类型（支出/收入/转账/余额调整）、标题、金额（BigDecimal）、**`convertedAmount`（换算到账簿币种后的金额）**、账户、转入账户、收付款方、**`confirm`（是否已确认——未确认的流水不影响余额）**、**`include`（是否计入统计）**、创建时间（业务时间）与插入时间、创建人、标签、附件；
- **CategoryRelation（流水 ↔ 分类，多对多带金额）**：一笔流水可按金额拆到多个分类（如一张购物小票拆成食品/日用），各自有原币与换算金额；
- Payee、Tag（树状）、NoteDay（纪念日/提醒）。

## 可借鉴

- [MN1] 账簿级默认值（默认账户/分类/币种）—— 减少录入。
- [MN2] 流水“已确认/未确认”与“计入统计/不计入统计”两个独立开关。
- [MN3] 流水按金额拆分到多个分类（多对多带金额）。
- [MN4] 原币金额 + 账簿币种换算金额同存。

## 不采用 / 风险

- 单式；金额 BigDecimal 未区分币种精度；无期间/审计。

## 对新系统的启示

- 交易状态区分“草稿/待确认”与“已过账”；统计口径可排除特定交易（如内部测试单、赠送码）而不删除它们（`exclude_from_reports` + 原因）；
- 交易类型（业务模板）带默认值（账户、维度、币种、手续费规则）。
