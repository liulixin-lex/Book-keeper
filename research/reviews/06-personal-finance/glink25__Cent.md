# glink25/Cent

- 分类：06 个人/多人协作记账（Web PWA，数据存于 GitHub 仓库）
- 语言 / 许可证 / 最近提交：TypeScript (React, pnpm monorepo) / CC BY-NC-SA 4.0（非商业）/ 2026-09-22
- 审查范围：`README.md`、`apps/cent`、`packages/{zen,chaty}`

## 定位

“无服务器”的多人协作记账：账本数据以 JSON 文件提交到用户自己的 GitHub 私有仓库，利用 Git 提交做同步与版本控制，多人通过仓库协作者权限共享账本；内置 AI 对话（chaty）辅助记账与分析。

## 可借鉴

- [CT1] 以 Git 提交历史作为天然的审计轨迹与可回滚版本（每次保存 = 一次提交）。
- [CT2] 二级分类 + 自定义标签 + 预算 + 统计的极简组合；PWA 离线可用。
- [CT3] 协作权限直接复用外部平台（仓库协作者）。

## 不采用 / 风险

- 非商业许可；GitHub 作为数据库无法支撑多人并发写与复杂查询；单式记账。

## 对新系统的启示

- “每次变更都可回滚到任意版本”的体验，可由事件日志 + 冲正实现；数据导出到 Git（JSON/Beancount）可作为异地备份选项。
