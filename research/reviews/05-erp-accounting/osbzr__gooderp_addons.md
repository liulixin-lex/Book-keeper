# osbzr/gooderp_addons（GoodERP，中国本地化 ERP）

- 分类：05 ERP 会计模块（中国会计习惯）
- 语言 / 许可证 / 最近提交：Python（Odoo 10/12 框架）/ AGPL-3.0（历史版本）/ GitHub 主干现仅剩 README（2019 年后源码转为捐赠获取）；本次从历史提交 `a5ae08e`（2019-08）读取 `finance` 模块
- 审查范围：`finance/models/{finance,voucher_template,exchange,trial_balance,balance_sheet,report_auxiliary_accounting}.py`

## 定位

“中国用户数最多的开源 ERP”之一，财务模块完全按国内会计实务设计：凭证字号、科目级次、辅助核算、期末调汇、结账。

## 数据模型

- **凭证（voucher）**：**凭证字**（记/收/付/转，含打印标题）、**凭证号**（按期间自动重置的序列）、凭证日期、**会计期间**、**附件张数**、状态（草稿/已确认/已作废）、是否结账凭证、是否初始化凭证；
- **凭证行**：**摘要**（必填）、科目、借方或贷方（只能一侧）、往来单位、**外币金额 + 外币币别 + 汇率**、数量 + 商品、**辅助核算项**（客户、供应商、部门、项目、员工…）、生成来源（init_obj：由哪个单据生成）；
- **会计期间**：年 + 月，`已结账` 标记；日期找不到期间或期间已结账一律拒绝；
- **科目**：编码、名称、**余额方向**、**辅助核算类型**、成本类型、视图/明细科目（只能往**下级（明细）科目**记账）、**会计要素**（资产/负债/共同/权益/成本/损益）、**科目级次**、外币币别、**是否期末调汇**、**借方禁止 / 贷方禁止 + 自定义提示语**（例如“收入类科目禁止借方记账，请使用红字冲销”）。

## 记账逻辑与算法

- 确认凭证：校验期间未结账、借贷平衡、科目为明细科目、借贷方向未被禁止；**由其他单据生成的凭证不能单独撤销确认**（必须从源单据撤销）；已确认凭证修改需先撤销确认；
- **期末调汇**：对设置了“期末调汇”的外币科目和往来单位，按期末汇率计算差额生成调汇凭证；
- 结账：生成损益结转凭证，标记期间已结账；凭证模板（voucher_template）快速录入；
- 报表：科目余额表、资产负债表、利润表、辅助核算明细账。

## 可借鉴

- [GE1] 凭证字 + 期间内连续凭证号 + 附件张数（国内会计习惯，便于纸质/电子凭证对应）。
- [GE2] 科目“借方禁止/贷方禁止 + 提示语”——用数据规则防止错误方向记账。
- [GE3] 辅助核算（客户/供应商/部门/项目）挂在凭证行上，科目设定需要哪些辅助核算。
- [GE4] 只能向明细科目记账；会计要素分类（含“共同类”）。
- [GE5] 系统生成的凭证只能从源单据撤销，保持单据与凭证一致。
- [GE6] 期末调汇（按科目开关）。

## 不采用 / 风险

- 金额浮点；框架老旧；源码已不在 GitHub 主干维护。

## 对新系统的启示

- 中文场景的凭证展示：凭证字号、摘要、附件数；
- 科目方向限制规则（禁止借/贷 + 提示），例如“收入类科目禁止直接借方记账”；
- 科目上声明“必填维度”（辅助核算），录入时强校验；
- 系统生成的交易（来自导入/模板）与手工交易区分，撤销路径受控。
