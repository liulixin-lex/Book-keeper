# r3f/china-chart-of-accounts

- 分类：09 API 规范与标准（中国会计科目表模板）
- 语言 / 许可证 / 最近提交：CSV / GPL-3.0 / 2020
- 审查范围：`zh_Chart_of_Accounts_Importer.csv`（约 228 个科目）、README

## 定位

ERPNext 的中国科目表导入模板：基于财政部《企业会计准则》科目编码（一级科目 4 位，二级用 `.01` 后缀），映射到 ERPNext 根类型（Asset / Liability / Equity / Income / Expense）与科目类型。

## 内容要点

- 列：科目名称、上级科目、科目编号、是否分组、科目类型、根类型；
- 编码体系：1xxx 资产、2xxx 负债、3xxx 共同类（模板归入权益）、4xxx 权益、5xxx 成本、6xxx 损益（国标），模板做了简化合并；
- 科目类型中英对照：银行、现金、应收、应付、固定资产、折旧、销货成本、库存、税项、四舍五入（尾差）、临时科目……
- 规则：Bank / Cash / Stock 只能作分组；必须存在 COGS、折旧、固定资产、应付、应收、库存调整等关键类型科目。

## 质量问题（审查发现）

- 部分子科目编号与上级不一致（如“员工 1231.01”挂在“其他应收款 1221”下，而 1231 是“坏账准备”）；
- 包含大量金融业（存放中央银行、拆出资金、保户质押贷款等）科目，个人/小微业务用不上；
- 国标 3xxx“共同类”被强行并入权益。

## 可借鉴

- [CN-1] 国标一级科目编码 + 名称作为“标准科目”参考，便于与中国会计报表对齐。
- [CN-2] 科目“类型”（功能角色）与“根类型”（报表分类）分离；关键角色科目必须存在。

## 对新系统的启示

1. 科目表模板化：内置“精简小微/个人模板”，科目可映射到国标代码（`standard_code` 字段），报表可按国标汇总；
2. 科目导入需校验：编码与上级前缀一致、根类型与上级一致、角色科目唯一/必须存在。
